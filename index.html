About Pexora

Pexora is a document utility built around one rule: tools should only claim to work if they actually do. Everything under "All tools" that isn't explicitly marked requires backend runs fully in your browser using pdf-lib for document editing and pdf.js for rendering and text extraction — the same engines used by Firefox's built‑in PDF viewer.

Privacy

What we collect: this build collects nothing — there is no analytics script, no cookie banner, and no account system wired up.

What happens to your files: for every tool on this page except the two marked "requires backend," your file is read directly into browser memory via the File API and processed with client‑side libraries. It is never attached to a network request.

The two backend‑only conversions: PDF↔Word and HTML→PDF need server‑side rendering engines that don't exist in a browser. In this build those tools are disabled with an explanation rather than faked — see the backend scaffold for how they'd be implemented securely.

Third parties: two libraries are loaded from a CDN (cdnjs) at page load — pdf-lib and pdf.js. No file data is sent to that CDN; it only serves the static library code.
